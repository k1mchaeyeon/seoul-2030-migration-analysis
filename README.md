# 서울시 25개 자치구의 20·30대 순이동과 주거비·고용 환경의 관계 분석

2021~2024년 서울 25개 자치구의 20대·30대 순이동을 주거비, 고용률,
사업체 종사자수와 함께 비교한 프로젝트입니다.

## 실행 순서

```bash
source .venv/bin/activate
python 02_preprocessing.py
python 03_analysis.py
python 04_visualization.py
streamlit run app.py
```

`data/raw`에는 내려받은 원본 파일을 보관합니다. 
전처리 결과는 `data/processed`, 분석 결과는 `results`에 저장됩니다.

## 주요 지표

- 순이동자수: 전입자수 - 전출자수
- 순이동률: 순이동자수 / 연앙인구 × 1,000
- 연앙인구: 전년도 말 인구와 해당 연도 말 인구의 평균
- 전세환산 주거비: 전세는 `보증금`, 월세는 `보증금 + 월세×12÷0.05`로 계약별 환산한 뒤 자치구별 중앙값 사용
- 고용률: 20대 참고지표는 15–29세, 30대 참고지표는 30–49세 자료 사용(정확한 연령 범위는 아님)
- 사업체 종사자수: 근무지 기준 절대 종사자수

## 해석할 때 주의할 점

- 전월세 계약 자료에는 계약자의 연령이 없습니다.
- 5.0%는 연도 간 비교를 위한 고정 분석 전환율이며 법정 상한이나 개별 계약의 실제 전환율이 아닙니다.
- 순이동과 고용률의 연령 구간이 정확히 일치하지 않습니다.
- 사업체 종사자수는 지역의 일자리 규모를 보여주는 대리 지표입니다.
- 상관관계는 개인의 이사 원인이나 정책 효과를 뜻하지 않습니다.
